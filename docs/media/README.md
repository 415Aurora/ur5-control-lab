# Curated project media

These are unchanged copies of existing local artifacts, selected for the repository documentation. Original files remain in their original locations. See `manifest.json` for source paths, file sizes, SHA-256 and interpretation boundaries. Relative source paths describe the preparation workspace; source directories need not be published with this gallery.

The image gallery and captions are in [Visual results](../visual-results.md). Do not treat a simulation screenshot as a physical-robot test or a loss curve as a closed-loop success result. This folder does not change the licensing of upstream models, tools or collaborator contributions.
